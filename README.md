# Urban Brew ☕

## Description
Urban Brew is a coffee shop mobile app made with Flutter. Customers can view products, order coffee, check their order history, and pay online using Xendit.

## Features
- View coffee products
- Place orders
- View order history
- Check payment status
- Online payment using Xendit

## Requirements
- Flutter SDK
- Android Studio or Visual Studio Code
- Supabase account
- Xendit account

## Installation
1. Download or clone the project.
2. Open the project folder.
3. Open the terminal.
4. Run `flutter pub get`.
5. Configure the Supabase URL and key.
6. Run `flutter run`.

## Supabase Configuration
1. Open your Supabase project.
2. Get your project URL and publishable key (or anon key).
3. Add them to the app's configuration file.
4. Make sure the required database tables and Edge Functions are configured.

## Build and Install APK
1. Run `flutter build apk --release`.
2. Find the APK at `build/app/outputs/flutter-apk/app-release.apk`.
3. Transfer the APK to an Android phone and install it.
